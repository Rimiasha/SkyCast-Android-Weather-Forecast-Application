# 🌤️SkyCast-Android Weather Forecast Application

## Overview

This project demonstrates a native Android Weather App built with Kotlin and Jetpack Compose. The app collects real-time weather data based on the user's location and displays current conditions, a 5-day forecast, and a home-screen widget for at-a-glance updates.

## 📂 Data Source

We use the OpenWeatherMap API for weather data.

## 🛠️ Technologies Used

**✅ Kotlin**

**✅ Jetpack Compose (Modern Android UI Toolkit)**

**✅ Retrofit (API Requests & JSON Parsing)**

**✅ Google Play Services Location (Current Location Access)**

**✅ Coil (Image Loading for Weather Icons)**

**✅ WorkManager (Background Widget Updates)**

## 🚀 Features

✅ Location-Based Current Weather

✅ Temperature, Humidity & Wind Speed Display

✅ Sunrise & Sunset Timings

✅ 5-Day Weather Forecast

✅ Manual Refresh Option

✅ Home-Screen Widget with Auto-Updates

✅ Displaying Real-Time Weather Conditions
